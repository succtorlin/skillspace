它做什么

没有容器，没有装饰——每一项都是你机器上真实存在的东西。

01 / 卡片墙

把目录变成可读的东西

逐个读取 SKILL.md 的 frontmatter，取出名称与描述，渲染成一面可扫视的墙。

自动分类 · 可搜索
现在就看
02 / 口令

一键生成调用口令

选一个 Skill，填上具体任务，SkillSpace 生成一段口令，复制粘贴即可发送给 agent。

路径模式 / 完整模式
试一次

让 agent 自己按用途分类，回传结果，之后一句话就能唤起一整组 Skill。

JSON 回传 · 可离线导入
