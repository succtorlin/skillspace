# The Board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Watch it happen — a project rail, a board of the active project's orders grouped by status, a goal composer that shows the PM's decomposition, and an order drawer with prompt, acceptance, live log, exit/failure, cancel and dispatch; then verdict badges and attempt chains once plan 2d lands.

**Architecture:** Three new classic scripts (`public/board.js`, `public/order-drawer.js`, `public/goal-panel.js`) beside the existing `app.js`, all rendering from pure helpers added to `public/pure.js` (which `node --test` can `require`). State reaches the page by **polling** — `GET /api/orders?project=`, `/api/goals?project=`, `/api/scheduler` every 2 s, and the order log by **byte offset** every 1 s — because nothing in the server emits an event for a state change (reasons in "Live updates" below). One backend task adds the only route the UI cannot do without: `GET /api/orders/:id/log` (and the PM's `GET /api/goals/:id/log`). Styling extends the existing token system in `public/style.css` from a new `public/board.css` that may only read tokens.

**Tech Stack:** Plain Node ≥21, zero runtime dependencies added, `node:test`, vanilla JS classic scripts, no framework, no build step, no webfonts. Builds on plans 2a–2c (`lib/{store,projects,orders,worktrees,runner,dispatch,goals,pm,plan,scheduler}.js`, `routes/{projects,orders,goals,scheduler,common,deps}.js`).

## Live updates: polling, and why not SSE

- **The board polls** three GETs every 2 000 ms while the tab is visible, and stops while it is hidden. Every state change the board shows is a file write in `lib/orders`/`lib/goals` made by dispatch or the scheduler, and **nothing emits an event for one** — the scheduler itself is a 1 s poll loop for the same reason (lib/scheduler.js header: "A POLL LOOP RATHER THAN AN EVENT"). An SSE board would need an event bus threaded through `orders.patch`, `goals.patch` and `scheduler.stats`, which is a backend redesign, not a board.
- **The order log polls by byte offset** (`GET /api/orders/:id/log?from=N`, 1 000 ms) while the drawer is open. Spec §7 said "SSE while running, file when finished"; the offset poll is that contract with one mechanism instead of two. It resumes across a server restart and a drawer reopen (the offset is the client's), needs no file watcher (`fs.watch` is unreliable on macOS for appends), serves running and finished orders through the same code, and is testable over plain HTTP. Latency ≤ 1 s on agent output is acceptable.
- **Connection budget.** HTTP/1.1 allows six connections per origin. `/api/run`'s SSE already holds one while a Skill runs; a streaming board plus a streaming log would hold two more for as long as the tab is open.
- **Cost, stated.** `orders.list()` opens every record synchronously (lib/orders measured 41 ms at 2 000 orders). Fine at the tens this tool holds; at thousands the index lib/orders already names becomes due (gap #9).

## Standing questions for every task in this plan

Plans 2a–2c found their worst errors in their own text, and the console's own history (railState, focus restoration, the `esc(0)` quirk) shows the same shapes on the front end. Carry these as questions:

1. **Does this render survive every record shape `lib/` already admits?** `usable()` checks only `id` and `createdAt`: `status` may be missing or misspelt, `title` may be `''`, `seq` is `null` on one-off orders, `orderIds` may not be an array. Render "未知状态" — never drop the row, never throw mid-render.
2. **Does a failed or empty response read as "nothing here"?** `railState` exists because a 500 once rendered as "add a project". Error, empty and filtered are three states with three messages; a failed poll after a good one keeps the good data **marked stale**.
3. **Does this copy claim something the backend does not do?** No review window with the scheduler on; `done` ≠ succeeded; `maxOrdersPerDay` counts *creations*; `inFlight` counts only the loop's dispatches; cancel only SIGTERMs; limits bound count and duration, **never money**.
4. **Does this re-render destroy the node the keyboard user is standing on?** `loadProjects` had to learn this. The board re-renders only when its signature changes and restores focus by `data-order-id`.
5. **Is this response still about what is on screen?** A poll for project A can land after the user picked B; a log slice for order X after the drawer moved to Y. Every async render checks a generation or id first.
6. **Does this action spawn or kill a credentialed agent, and does it have exactly one door and a confirmation?** Dispatch spawns; cancel kills; closing a live `/api/run` stream kills that agent (server `req.on('close')` reaps it).
7. **Is `esc()` being handed a number?** `esc(0)` returns `''` (pinned quirk in test/pure.test.js). Counts and exit codes go through `String()` first.
8. **Was this screenshot taken against the CSS and JS on disk?** Static files were served with no `Cache-Control`; Task 2 adds `no-cache`, and every browser check still hard-reloads first.
9. **Contrast measured, not assumed.** `--muted` on `--ground-3` is 4.34:1. A new text/background pair gets a number in the task that introduces it.

```js
'use strict';
const fs = require('fs');
const path = require('path');

// A byte slice of an append-only log, for a browser that polls it by offset.
//
// Why an offset poll and not a stream is argued in docs/plans/2026-10-12-
// board.md ("Live updates"). This module owns the one subtle part: never hand
// back half a UTF-8 character. lib/runner writes through a StringDecoder, so
// the FILE holds whole characters - but a slice cap can land inside one, and
// a reader can catch the file between two writes. Either way the trailing
// partial character is held back and `next` stops before it, so the client's
// next request starts on a boundary.
//
// Known limits:
// - A FILE WHOSE BYTES ARE NOT UTF-8 is emitted as-is and decoded with
//   replacement characters. Only a TRAILING incomplete sequence is held back;
//   malformed bytes mid-file are not ours to repair.
// - `from` is trusted to be a boundary this module returned. A client that
//   invents an offset inside a character gets replacement characters for it.

const MAX_SLICE = 64 * 1024;

function logPath(root, id) {
  return path.join(root, 'logs', `${id}.log`);
}

// How many of the first n bytes form complete UTF-8 characters.
function completeUtf8Length(buf, n) {
  let i = n - 1;
  let cont = 0;
  while (i >= 0 && cont < 3 && (buf[i] & 0xc0) === 0x80) { i--; cont++; }
  if (i < 0) return n; // nothing but continuation bytes: not a sequence we can complete
  const lead = buf[i];
  const need = lead >= 0xf0 ? 4 : lead >= 0xe0 ? 3 : lead >= 0xc0 ? 2 : 1;
  return cont + 1 >= need ? n : i;
}

function readSlice(file, fromRaw, max = MAX_SLICE) {
  let fd;
  try {
    fd = fs.openSync(file, 'r');
  } catch (e) {
    if (e && e.code === 'ENOENT') return { text: '', from: 0, next: 0, size: 0, exists: false, reset: false };
    throw e;
  }
  try {
    const size = fs.fstatSync(fd).size;
    const asked = typeof fromRaw === 'string' && fromRaw.trim() !== '' ? Number(fromRaw)
      : typeof fromRaw === 'number' ? fromRaw : NaN;
    const valid = Number.isSafeInteger(asked) && asked >= 0;
    const reset = valid && asked > size;
    const from = valid && !reset ? asked : 0;
    const want = Math.min(max, size - from);
    const buf = Buffer.alloc(Math.max(0, want));
    const n = want > 0 ? fs.readSync(fd, buf, 0, want, from) : 0;
    const keep = completeUtf8Length(buf, n);
    return { text: buf.toString('utf8', 0, keep), from, next: from + keep, size, exists: true, reset };
  } finally {
    fs.closeSync(fd);
  }
}

module.exports = { readSlice, logPath, MAX_SLICE };
```

Create `test/helpers/quiet-server.js` (not matched by `test/**/*.test.js`, so `npm test` does not run it as a suite):

```js
'use strict';
const fs = require('fs');
const os = require('os');
const path = require('path');
const net = require('net');
const { spawn } = require('child_process');

// A server for routes that spawn NOTHING. Unlike the agent-spawning suites it
// needs no shim: HOME is an empty temp dir and PATH is /usr/bin:/bin, so no
// agent can be discovered at all - and that is ASSERTED, not assumed, because
// a quiet server that found the developer's real `claude` would be one typo
// away from running it.
function freePort() {
  return new Promise((resolve, reject) => {
    const s = net.createServer();
    s.on('error', reject);
    s.listen(0, '127.0.0.1', () => { const { port } = s.address(); s.close(() => resolve(port)); });
  });
}

async function startQuietServer(created) {
  const home = fs.mkdtempSync(path.join(os.tmpdir(), 'skillspace-quiethome-'));
  const store = fs.mkdtempSync(path.join(os.tmpdir(), 'skillspace-quietstore-'));
  created.push(home, store);
  const port = await freePort();
  const proc = spawn(process.execPath, ['server.js'], {
    cwd: path.join(__dirname, '..', '..'),
    env: {
      PATH: '/usr/bin:/bin',
      HOME: home,
      TMPDIR: os.tmpdir(),
      SKILLSPACE_HOME: store,
      SKILLSPACE_EXPERTS_FILE: path.join(store, 'experts.json'),
      SKILLSPACE_SCHEDULER: '0',
      PORT: String(port),
    },
    stdio: ['ignore', 'pipe', 'pipe'],
  });
  let out = '';
  proc.stdout.on('data', (c) => (out += c));
  proc.stderr.on('data', (c) => (out += c));
  const base = `http://127.0.0.1:${port}`;
  const deadline = Date.now() + 15000;
  for (;;) {
    if (proc.exitCode !== null) throw new Error('quiet server exited early: ' + out);
    try { if ((await fetch(base + '/api/config')).ok) break; } catch (_) {}
    if (Date.now() > deadline) { proc.kill('SIGKILL'); throw new Error('quiet server did not start: ' + out); }
    await new Promise((r) => setTimeout(r, 100));
  }
  const cfg = await (await fetch(base + '/api/config')).json();
  if (!Array.isArray(cfg.agents) || cfg.agents.length !== 0) {
    proc.kill('SIGKILL');
    throw new Error('quiet server discovered an agent: ' + JSON.stringify(cfg.agents));
  }
  return { proc, base, store };
}

async function stopQuietServer(proc) {
  if (!proc || proc.exitCode !== null) return;
  proc.kill('SIGTERM');
  const deadline = Date.now() + 8000;
  while (proc.exitCode === null && Date.now() < deadline) await new Promise((r) => setTimeout(r, 25));
  if (proc.exitCode === null) proc.kill('SIGKILL');
}

module.exports = { startQuietServer, stopQuietServer };
```

// apart on purpose (spec §8a): one is SkillSpace killing a stuck agent, the
// other is the agent giving up on its own, and they call for different fixes.

function failureView(order, budget) {

  if (st === 'cancelled') {

        : '取消时它还没开始运行。',

  if (st === 'interrupted') {
    return {
      kind: 'interrupted', title: '被中断',
      detail: 'SkillSpace 重启时它还在运行。那个进程已不受管，结果未知——不按成功算。',
    };
  }
  if (st !== 'failed') return null;
  if (order.error === 'timeout') {
    const limit = budget && Number.isFinite(budget.orderTimeoutMs) ? fmtDuration(budget.orderTimeoutMs) : null;
    return {
      kind: 'timeout', title: '超时，被终止',
      detail: `运行超过项目的时长上限${limit ? `（现在是 ${limit}）` : ''}，被 SkillSpace 终止。不是 agent 自己退出，所以没有退出码。`,

  if (!order.startedAt) {
    return { kind: 'never-started', title: '没有启动', detail: order.error ? String(order.error) : '原因没有记录。' };
  }

  { key: 'queued', label: '排队' },
  { key: 'failed', label: '失败 · 中断' },

  const st = order && order.status;
  if (st === 'interrupted') return 'failed';
  return BOARD_GROUPS.some((g) => g.key === st) ? st : 'unknown';
}
function boardTime(s) {
  const n = Date.parse(s || '');
  return Number.isFinite(n) ? n : 0;
}
function boardSortFor(key, list) {
  const copy = list.slice();
  if (key === 'queued') {
    return copy.sort((a, b) => boardTime(a.createdAt) - boardTime(b.createdAt) || String(a.id).localeCompare(String(b.id)));
  }
  if (key === 'running') return copy.sort((a, b) => boardTime(a.startedAt) - boardTime(b.startedAt));
  return copy.sort((a, b) => boardTime(b.finishedAt) - boardTime(a.finishedAt) || String(b.id).localeCompare(String(a.id)));

function groupOrders(orders) {
  const list = Array.isArray(orders) ? orders.filter(Boolean) : [];

    else unknown.push(o);

// that matches nothing is not "this project has no orders".
function boardState(ok, data, onlyIds) {

}

}

// The scheduler, read the way routes/scheduler.js says it must be read:
// `running` is "timer armed", not progress (lastTickAt answers that), and
// lastError is never cleared, so only a rising `errors` count or a fresh
// lastErrorAt means "erroring now". `prev` is the previous poll, or null.
function schedulerView(prev, cur, now) {
  const s = cur && cur.scheduler;
  if (!s || typeof s !== 'object') {
    return { kind: 'unknown', text: '读不到调度器状态', detail: '订单会不会自动开始，现在无法确定。', lastError: null };
  }
  const errAt = Date.parse(s.lastErrorAt || '');
  const lastError = s.lastError && Number.isFinite(errAt)
    ? { message: String(s.lastError), ago: fmtDuration(now - errAt) + '前' }
    : null;
  if (!s.running) {
    return { kind: 'off', text: '调度器关闭', detail: '订单停在排队，逐单点「派发」才会运行。', lastError };
  }
  const interval = Number.isFinite(s.intervalMs) && s.intervalMs > 0 ? s.intervalMs : 1000;
  const tickAt = Date.parse(s.lastTickAt || '');
  if (!Number.isFinite(tickAt) || now - tickAt > Math.max(10000, interval * 10)) {
    return {
      kind: 'stalled', text: '调度器没有在轮询',
      detail: Number.isFinite(tickAt) ? `上次轮询在 ${fmtDuration(now - tickAt)}前。` : '启动后还没轮询过。',
      lastError,
    };
  }
  const p = prev && prev.scheduler;
  const rising = !!p && Number.isFinite(p.errors) && Number.isFinite(s.errors) && s.errors > p.errors;
  const fresh = Number.isFinite(errAt) && now - errAt < interval * 3;
  if (rising || fresh) {
    return { kind: 'erroring', text: '调度器在报错', detail: String(s.lastError || '没有记录错误内容'), lastError };
  }
  if (Number.isFinite(s.pausedProjects) && s.pausedProjects > 0) {
    return {
      kind: 'paused', text: `${s.pausedProjects} 个项目暂停中`,
      detail: '连续几单没能启动，暂停一分钟后再试。状态接口没有说是哪个项目。',
      lastError,
    };
  }
  const skipAt = s.lastSkip ? Date.parse(s.lastSkip.at || '') : NaN;
  if (Number.isFinite(skipAt) && now - skipAt < interval * 3) {
    return {
      kind: 'blocked', text: '有订单被挡住',
      detail: `${String(s.lastSkip.reason || '')}（可能是别的项目的订单）`,
      lastError,
    };

  }
  return { kind: 'idle', text: '调度器运行中 · 空闲', detail: null, lastError };
}

function orderTransitions(prev, next) {
  if (!Array.isArray(prev) || !Array.isArray(next)) return [];
  const before = new Map(prev.filter(Boolean).map((o) => [o.id, o.status]));
  const out = [];
  for (const o of next) {
    if (!o) continue;
    if (!before.has(o.id)) out.push({ id: o.id, from: null, to: o.status, order: o });
    else if (before.get(o.id) !== o.status) out.push({ id: o.id, from: before.get(o.id), to: o.status, order: o });
  }
  return out;
}

// ONE polite sentence per poll, never a sentence per row: a five-order goal

function announcement(transitions) {
  if (!Array.isArray(transitions) || !transitions.length) return '';
  const added = transitions.filter((t) => t.from === null).length;
  const moved = transitions.filter((t) => t.from !== null);
  const parts = moved.slice(0, 3).map((t) => {
    const f = failureView(t.order, null);

  if (added) parts.unshift(`新增 ${added} 单`);

}

// Done means settled AND drained: a settled order may still have bytes the
// client has not fetched (the route reads status before the slice for this).
function logStep(body, live) {
  const log = body && body.log;
  if (!log || typeof log !== 'object' || !Number.isSafeInteger(log.next) || log.next < 0) return { ok: false };
  const size = Number.isSafeInteger(log.size) ? log.size : log.next;
  const more = log.next < size;
  return {
    ok: true, text: typeof log.text === 'string' ? log.text : '', next: log.next,
    reset: log.reset === true, exists: log.exists !== false, more, done: !live && !more,
  };
}

// The DOM keeps the last LOG_DOM_CAP characters; the full log stays on disk.
const LOG_DOM_CAP = 200000;
function appendCapped(current, chunk, cap) {
  const max = Number.isInteger(cap) && cap > 0 ? cap : LOG_DOM_CAP;
  const joined = String(current == null ? '' : current) + String(chunk == null ? '' : chunk);
  if (joined.length <= max) return { text: joined, dropped: 0 };
  let cut = joined.length - max;
  const code = joined.charCodeAt(cut);
  if (code >= 0xdc00 && code <= 0xdfff) cut += 1; // never begin on the low half of a pair
  return { text: joined.slice(cut), dropped: cut };
}

// Every answer the dispatch and cancel routes give, in the console's language.
// Losing the claim to the scheduler is ok:true - the order runs either way.
function orderActionOutcome(action, status, body) {
  const err = body && typeof body.error === 'string' ? body.error : '';
  const verb = action === 'cancel' ? '取消' : '派发';
  if (status === 0) return { ok: false, text: '无法连接服务器' };
  if (status === 200) return { ok: true, text: action === 'cancel' ? '已发出取消' : '已派发，等它开始运行' };
  if (status === 404) return { ok: false, text: '这一单不存在了' };
  if (status === 409 && /already being dispatched/.test(err)) return { ok: true, text: '调度器已经领走了这一单' };
  if (status === 409 && body && body.order && body.order.status) {
    return { ok: false, text: `这一单已经是「${orderStatusText(body.order.status)}」了` };
  }
  if (status === 409) {
    const m = /^order is already (\w+)$/.exec(err);
    return { ok: false, text: m ? `这一单已经是「${orderStatusText(m[1])}」了` : `${verb}不了：${err || '状态冲突'}` };

  if (status === 429) return { ok: false, text: `同时运行的 agent 已满，稍后再试（${err}）` };

const BOARD_POLL_MS = 2000;

// { ok, status, body }. status 0 = no response at all (network / server down).
async function boardGetJson(url) {
  try {
    const r = await fetch(url);
    let body = null;
    try { body = await r.json(); } catch (_) {}
    return { ok: r.ok, status: r.status, body };
  } catch (_) {
    return { ok: false, status: 0, body: null };
  }
}
async function boardPostJson(url, payload) {
  try {
    const r = await fetch(url, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(payload || {}),
    });
    let body = null;
    try { body = await r.json(); } catch (_) {}
    return { ok: r.ok, status: r.status, body };
  } catch (_) {
    return { ok: false, status: 0, body: null };
  }
}

function boardSchedule(delay) {
  clearTimeout(board.timer);
  if (!board.project || document.hidden) return;
  board = { ...board, timer: setTimeout(boardPoll, delay) };
}

// Called from the drawer and goal panel after an action.
function boardRefresh() { boardSchedule(0); }

async function boardPoll() {
  const project = board.project;
  const q = project && boardQuery(project.id);
  if (!q || board.inFlight) return;
  board = { ...board, inFlight: true };
  const [o, g, s] = await Promise.all([
    boardGetJson(q),
    boardGetJson('/api/goals?project=' + encodeURIComponent(project.id)),
    boardGetJson('/api/scheduler'),
  ]);
  board = { ...board, inFlight: false };
  // Standing question 5: the user may have picked another project while this
  // was in flight. Its answer is about a board no longer on screen.
  if (!board.project || board.project.id !== project.id) return boardSchedule(0);
  boardApply(o, g, s);
  boardSchedule(BOARD_POLL_MS);
}

function boardApply(o, g, s) {
  const st = boardState(o.ok, o.body, null);
  const goals = g.ok && g.body && Array.isArray(g.body.goals) ? g.body.goals : board.goals;
  const sched = s.ok && s.body ? s.body : null;
  if (st.kind === 'error') {
    const why = st.message || (o.status ? `HTTP ${o.status}` : '无法连接服务器');
    board = { ...board, error: why, prevSched: board.sched, sched, goals };
  } else {
    const transitions = board.orders ? orderTransitions(board.orders, st.orders) : [];
    board = { ...board, orders: st.orders, error: null, okAt: Date.now(), prevSched: board.sched, sched, goals };
    const msg = announcement(transitions);
    if (msg) boardEl('board-live').textContent = msg;
  }
  boardRender();
  if (typeof goalPanelRender === 'function') goalPanelRender();
}

document.addEventListener('visibilitychange', () => {
  if (document.hidden) clearTimeout(board.timer);
  else boardSchedule(0);
});

async function drawerRefreshOrder(gen) {

function drawerLogNote(step, status) {
  const parts = [];
  if (!step.exists) {
    parts.push(status === 'queued' ? '还没开始运行，没有日志。' : '这一单没有日志（它没有启动）。');

  }
  if (step.more) parts.push('正在追上日志…');

async function drawerPollLog(gen) {
  if (drawer.gen !== gen || !drawerIsOpenFor(drawer.id)) return;
  const id = drawer.id;
  const r = await boardGetJson(`/api/orders/${encodeURIComponent(id)}/log?from=${String(drawer.from)}`);
  if (drawer.gen !== gen || !drawerIsOpenFor(id)) return;
  const status = r.body && r.body.status;
  const step = r.ok ? logStep(r.body, status === 'queued' || status === 'running') : { ok: false };
  const note = drawerEl('ord-log-note');
  if (!step.ok) {
    note.textContent = r.status === 404 ? '这一单不存在了。' : '日志读取失败，1 秒后重试。';
    if (r.status !== 404) drawer = { ...drawer, timer: setTimeout(() => drawerPollLog(gen), DRAWER_POLL_MS) };
    return;
  }
  const out = drawerEl('run-out');
  const stick = shouldStick(out.scrollTop, out.clientHeight, out.scrollHeight);
  if (step.reset) { out.textContent = ''; drawer = { ...drawer, dropped: 0 }; }
  if (step.text) {
    const capped = appendCapped(out.textContent, step.text, LOG_DOM_CAP);
    out.textContent = capped.text;
    drawer = { ...drawer, dropped: drawer.dropped + capped.dropped };
  }
  drawer = { ...drawer, from: step.next };
  if (stick) out.scrollTop = out.scrollHeight;
  note.textContent = drawerLogNote(step, status);
  if (!drawer.order || status !== drawer.order.status) await drawerRefreshOrder(gen);
  if (step.done) return; // settled and drained: nothing more will ever arrive
  if (drawer.gen !== gen) return;
  // While catching up on a long log, do not wait a full second between slices.
  drawer = { ...drawer, timer: setTimeout(() => drawerPollLog(gen), step.more ? 0 : DRAWER_POLL_MS) };
}

```js
// ---------- verdicts and attempts (plan 2d's fields) ----------
// Spec §3: succeeded = exited 0; verified = the PM checked it against its
// acceptance and accepted it. They are different claims and must LOOK
// different: that difference is the point of the spec.
function verdictOf(order) {
  if (!order) return null;
  if (order.verdict) return order.verdict;
  return order.status === 'verified' || order.status === 'rejected' ? order.status : null;
}
function verdictView(order) {
  if (!order) return null;
  const v = verdictOf(order);
  const reason = typeof order.verdictReason === 'string' && order.verdictReason.trim() ? order.verdictReason.trim() : null;
  if (v === 'verified') return { kind: 'verified', label: '已验收', glyph: '✓', detail: reason };
  if (v === 'rejected') return { kind: 'rejected', label: '驳回', glyph: '✕', detail: reason || '没有记录驳回理由' };
  if (v) return { kind: 'unknown', label: `验收状态无法识别（${String(v)}）`, glyph: '?', detail: null };
  if (order.status === 'succeeded') {
    return { kind: 'unjudged', label: '退出 0 · 未验收', glyph: '○', detail: '进程正常退出，但还没有人对照验收标准检查过结果。' };
  }
  return null;
}

// supersedes links a retry to the order it replaces (spec §12). Walks are
// cycle-safe and tolerate a predecessor the list does not hold.
function attemptChains(orders) {
  const list = Array.isArray(orders) ? orders.filter((o) => o && typeof o.id === 'string') : [];
  const byId = new Map(list.map((o) => [o.id, o]));
  const walked = new Map();
  for (const o of list) {
    const seen = new Set([o.id]);
    let cur = o;
    let depth = 0;
    let broken = false;
    while (typeof cur.supersedes === 'string' && cur.supersedes) {
      const prev = byId.get(cur.supersedes);
      if (!prev || seen.has(prev.id)) { broken = true; break; }
      seen.add(prev.id);
      cur = prev;
      depth += 1;
    }
    walked.set(o.id, { rootId: cur.id, attempt: depth + 1, broken });
  }
  const sizes = new Map();
  for (const w of walked.values()) sizes.set(w.rootId, (sizes.get(w.rootId) || 0) + 1);
  const superseded = new Set(list.map((o) => o.supersedes).filter((s) => typeof s === 'string' && s));
  const out = new Map();
  for (const [id, w] of walked) out.set(id, { ...w, of: sizes.get(w.rootId), latest: !superseded.has(id) });
  return out;
}
function latestAttempts(orders) {
  const info = attemptChains(orders);
  return (Array.isArray(orders) ? orders : []).filter((o) => o && info.get(o.id) && info.get(o.id).latest);
}
function attemptLabel(info, rootOrder) {
  if (!info) return '';
  const from = rootOrder ? ` · 源自 ⌐${seqLabel(rootOrder)}¬` : '';
  const gap = info.broken ? '（更早的记录读不到）' : '';
  return `第 ${info.attempt} 次尝试 · 共 ${info.of} 次${from}${gap}`;
}
```
